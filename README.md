# FocusFlow

A student-planning website built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Features
- Add, edit, complete, search, and delete assignments
- Track subject, due date, estimated time, and difficulty
- Dashboard with upcoming tasks, completion stats, and 7-day workload chart
- Suggested study blocks for the next seven days
- Workload warnings for busy due dates
- Progress tracking by subject
- Study reflection saved in the browser
- Compare estimated and actual time when completing an assignment
- Export your data as JSON

## Publish on GitHub Pages
1. Create a **public** repository named `focusflow` at https://github.com/new.
2. Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. After publishing, your site URL should look like `https://YOUR-USERNAME.github.io/focusflow/`.

## Important limitations
- Data is stored in this browser only. It will not sync between browsers or devices.
- There are no accounts, cloud database, reminders, or calendar integrations in this starter version.
- The suggested plan is an estimate, not a guarantee. Adjust it for your real availability and leave room for breaks.
- Avoid entering sensitive personal information.

## Edit the site
Edit the files locally or use GitHub's file editor. Commit changes to the `main` branch and GitHub Pages will republish the site.
